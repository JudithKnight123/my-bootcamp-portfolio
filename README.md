# my-bootcamp-portfolio

A personal portfolio webpage from scratch includes a contact form, projects, about section, header and navigation.

## Features - Week 1

- **Feature A:** Header - Bold central profile and background fills the full browser space
- **Feature B:** About me - Short paragraph about me
- **Feature C:** Projects - a flexbox featuring a clean layout of latest projects
- **Feature D:** Contact - a centered contact form with phone number and email
- **Feature E:** Footer - a simple footer

## Features - Week 2

- **Feature A:** Homepage page - 4 grid flexbox
- **Feature B:** About me page - Short paragraph about me
- **Feature C:** Services - A flexbox featuring a clean layout of my services
- **Feature D:** Contact - a contact form with phone number, email and address
- **Feature E:** Footer - a simple footer

## Features - Week 3

- **Feature A:** Bootstrap Layout - Converted the website to use Bootstrap's responsive grid system.
- **Feature B:** Navigation Bar - Added a responsive Bootstrap navigation bar with a dropdown menu.
- **Feature C:** jQuery UI Tabs - Implemented interactive tabs to organise content within the page.
- **Feature D:** Responsive Design - Improved the layout for mobile, tablet and desktop screen sizes.
- **Feature E:** Bootstrap Components - Added cards, buttons and utility classes to enhance the user interface.

## Technologies Used

- HTML5 / CSS
- BOOTSTRAP
- JQUERY
